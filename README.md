# Реестр судебных исков — Казахтелеком

Веб-приложение для ведения реестра входящих и исходящих судебных исков.

## Возможности

- добавление, редактирование и удаление исков;
- разделение на входящие и исходящие иски;
- поиск и фильтрация по ФИО, предмету, номеру дела, году, кварталу и результату;
- автоматическая отметка «ПРОИГРАН» и «Проигран частично»;
- формирование отчёта за квартал или год;
- печать отчёта и сохранение в PDF через браузер;
- экспорт реестра и отчёта в CSV;
- резервное копирование и восстановление данных;
- возможность загрузить логотип Казахтелекома.

## Запуск через GitHub Pages

1. Загрузите `index.html` в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`.
5. После публикации GitHub Pages предоставит ссылку на приложение.

## Данные

Данные реестра сохраняются в `localStorage` браузера. Для переноса данных между браузерами или компьютерами используйте кнопку **«Сохранить копию данных»**, а затем **«Загрузить копию»**.
